# GTA 6 Cloud Clipping — AI Agent Build Pack

This ZIP is a **build specification**, not a completed app. Upload/extract the ZIP into your cloud AI coding agent's workspace and paste the contents of MASTER_PROMPT.md as its initial instruction (or tell it to read that file first).

Contains:
- MASTER_PROMPT.md — agent instructions
- REQUIREMENTS.md — product behavior
- ARCHITECTURE.md — infrastructure and data flow
- IMPLEMENTATION_PLAN.md — milestones
- ACCEPTANCE_TESTS.md — verification criteria
- ENVIRONMENT.example — required cloud secrets/configuration
- DEPLOYMENT.md — production checklist

All recordings, AI jobs, files and deployment must live in cloud services, never the user's local PC. External credentials and creator permissions will be needed for real integration.
